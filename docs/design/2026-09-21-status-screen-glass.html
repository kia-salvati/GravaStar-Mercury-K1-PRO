Mercury K1 PRO — glass, in white, dark and black

Round 2: same read-only status screen, four glass treatments, each in three themes. Structures are A (readout stack) and D (rail + panel) from round 1 — the information architecture is unchanged. A small utility window has nothing behind it to blur, so each frame draws its own field behind the glass: Ambient is a slow, soft rendition of the keyboard's current effect and colour; Static is a designed gradient with grain. Click values inside a frame to change the preview state.

1 — Frosted cards structure Dbackdrop-filter

Discrete translucent panels — the rail and each section — float on the field with a 10 px gutter, so the effect shows between and through them. This is the fullest expression of "glass": the rail, Connection, Lighting and Sleep are four blurred cards.

Glass, and what it is for

  • Each card blurs the field at 16 px and lifts saturation 40 % so the effect colour reads as a tint through the panel rather than a smear.
  • Edge light: a 1 px border that is brighter on the top edge plus a 1 px inner highlight. In Black this is the only thing that makes a card a card — the fill is 5 % white, so the field and the true-black gutter stay black.
  • A faint outer glow in the effect colour (60 px, −30 px spread) ties cards to the field; it is off when lighting is Off.

Cost

  • Five blurred elements over an animated field is the most expensive variant here. If it stutters, design 4 is the same layering without the filter.

Contrast

  • Dark and Black fills are thin (6 % / 5 % white), so the ambient cap is set low (14 % / 26 %) to keep secondary text at ≥ 4.5 : 1 even under a white Always On at brightness 4. Black-theme worst case is 4.5 : 1 — passes with no headroom; the table below shows it live.

Default state here

  • 2.4G, 100 % full, Windmill (a mixed-colour effect — the colour row greys with the reason), brightness 1, speed 0, sleep 1 min.

2 — Single sheet structure Abackdrop-filter × 1

The whole window is one pane of glass set 10 px inside the frame. There are no boxes: hierarchy comes from type size, the 92 px label column and hairlines. The field is visible only as a rim around the sheet and as a soft tint through it.

Glass, and what it is for

  • One backdrop-filter (24 px blur) on one element — the cheapest way to get real blur. The sheet fill is heavier (72 % white / 72 % graphite / 55 % black) so the readout stays calm under any effect.
  • The rim is where the effect lives: with Windmill the edge of the window slowly cycles hue while the readout itself barely moves. Purposeful: peripheral confirmation that lighting is on, without competing with the numbers.
  • In Black the sheet is 55 % black over black — invisible by fill — so the top-edge light and inner highlight carry the pane; the rim glow makes the rest of the silhouette.

Pairs best with

  • The Static field: a designed gradient with grain gives the blur something to soften and the sheet then reads as frosted at all times, not only when an effect is animated. Toggle Field above to compare.

Default state here

  • Wired (battery not reported, sleep row muted), Always On in Cyan (palette 4), brightness 4, speed 0 — a static single colour, so the rim tint is steady.

3 — Rail of light structure Dbackdrop-filter, rail only

Glass only where it means something. The content panel is solid and fully opaque; the rail is the status element and it is lit by the effect: the ambient field is drawn inside the rail and blurred there. Because the rail also carries the glance glyphs (link, battery, effect swatch), "what is the keyboard doing right now" is one strip of light on the left, in every area of the app.

Glass, and what it is for

  • Blur is confined to a 60 px (or 200 px) column; the animated region is a fraction of the window, so this is the cheapest animated variant.
  • The content panel has no translucency at all, so its contrast is the plain token contrast — labels here use the most muted tier (--text-3), which is not permitted on glass in the other designs.
  • A 2 px strip on the rail's inner edge carries the effect colour at full strength (a gradient for mixed-colour effects) — the one place the colour is shown undiluted, because nothing is written over it. In Dark and Black the ambient cap keeps the field itself subtle, so the strip is what makes the rail read as lit; Off → strip and field both go dark, which is the honest reading.

Default state here

  • 2.4G at 23 % charging, Wave in Blue (palette 5), brightness 3, speed 2 — a single-colour animated effect so the rail visibly moves.

4 — No-blur glass structure Ano backdrop-filter

The fallback: the glass feel from layering alone. Four stacked panes (header, power, lighting/power groups, nav) with translucent fills, a top-edge light, an inner highlight and a diagonal sheen — and no filter anywhere. The trick is that the ambient field is already soft (large radial and conic gradients, blurred at draw time in CSS rather than at composite time), so translucency without blur still looks like frosted glass.

Glass, and what it is for

  • Fills are heavier than design 1 (74 % white / 78 % graphite / 72 % near-black) because there is no blur to homogenise what is behind; that is also why its contrast numbers are the best of the four.
  • The sheen (::before gradient, 50 % opacity) is a static highlight that reads as a reflective surface. It does not animate.
  • Only the field animates, and it is a single layer. With reduced motion the field is a still gradient and nothing else changes.

When to choose it

  • If designs 1–3 run hot on the laptop, or if Chrome's backdrop-filter stutters with the animated field. The fills and edges are shared tokens, so switching a shipped design to this one is a CSS-only change.

Default state here

  • 2.4G at 61 %, Custom (per-key colours), brightness 2, speed 1, sleep 5 min.

Composited contrast, measured

Computed at load and on every change, for the selected design, theme and field. Each row alpha-composites the panel fill over the field pixel, then measures the text against that result. Now is the current preview state (its colour at its brightness stage). Worst is the harshest pixel the field can produce: every palette colour and every mixed-effect hue at the ambient cap at brightness 4, or both ends of the static gradient — whichever is worse. Body and secondary text must clear 4.5 : 1 in the Worst column.
